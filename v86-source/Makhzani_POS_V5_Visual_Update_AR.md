# مخزني V5 — تحديث الهوية البصرية لواجهة البيع

- اعتماد لوحة ألوان كحلي/تركواز حديثة مع خلفية رمادية فاتحة وبطاقات بيضاء.
- تحسين التباين البصري للعناوين وأزرار الكاميرا والطباعة.
- توسيع المسافات الداخلية والحواف الدائرية والظلال الخفيفة.
- إبراز سلة المبيعات مع فصل بصري عن منطقة البحث والاختصارات.
- تحسين بطاقات المنتجات المختصرة وأزرار الكمية وبطاقة الإجمالي.
- تحديث لوحة ألوان الوضع الداكن أيضاً.
- لم يتم تغيير منطق المنتجات أو حساب العروض أو البيع أو حفظ المخزون أو الفواتير في هذا التحديث.
