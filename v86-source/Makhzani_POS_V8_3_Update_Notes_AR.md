# تحديث مخزني POS V8.3 — نسخة Windows

هذه حزمة مصدر محدثة مبنية على المشروع المرفق، مع تعديلات واجهة البيع والمرتجعات والباركود والتقارير والنسخ الاحتياطي، إضافة إلى إعداد Electron لإنتاج مثبت Windows بصيغة EXE.

## التعديلات الموجودة في المصدر
- واجهة البيع بخلفية بيضاء وكتابة سوداء وتباين واضح.
- دعم باركود مشترك لمجموعة أنواع، مع نافذة اختيار النوع والسعر والمخزون عند المسح.
- دعم باركود مستقل لكل نوع يضيف النوع مباشرة إلى الفاتورة.
- لكل نوع سجل منتج ومخزون وسعر شراء وبيع مستقل.
- المرتجعات تعيد الكمية إلى المخزون وتُسجل أثرها على المبيعات وتكلفة البضاعة والأرباح.
- زر رجوع في صفحة التقارير.
- النسخة الاحتياطية تتضمن مفاتيح اختصارات المنتجات، ويمكن اختيار Google Drive من نافذة المشاركة لرفعها يدوياً.
- إعداد Electron وNSIS لإنتاج مثبت Windows 64-bit.

## بناء Windows
استخدم ملف GitHub Actions المرفق بشكل منفصل باسم `build-windows.yml` في المسار `.github/workflows/build-windows.yml`. ارفع ملف ZIP إلى جذر المستودع بالاسم `Makhzani_POS_V8_3_Windows_Updated.zip` ثم شغّل Workflow.

## تنبيهات
- هذه حزمة مصدر وليست ملف EXE جاهزاً. يجب أن ينجح GitHub Actions أولاً.
- أُبقيت ملفات التطبيق الحالية وبيانات المشروع؛ لم يُجر اختبار تشغيل فعلي على Windows في هذه البيئة.
- النسخ الاحتياطي إلى Google Drive يتم يدوياً عبر نافذة المشاركة، وليس مزامنة تلقائية.
- اختبر البيع والمرتجعات والباركود وحفظ البيانات بعد إغلاق البرنامج على بيانات تجريبية قبل اعتمادها في المحل.
