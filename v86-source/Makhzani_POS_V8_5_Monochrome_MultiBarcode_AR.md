# Makhzani POS V8.5 – أبيض وأسود وباركودات متعددة

- توحيد ألوان واجهات التطبيق إلى الأبيض والأسود والرمادي فقط، بما يشمل الوضع الفاتح والداكن.
- إزالة ألوان البنفسجي والأزرق والأخضر والبرتقالي من عناصر الواجهة الأساسية والبطاقات والتنبيهات.
- دعم عدد غير محدود من الباركودات الإضافية لكل منتج من شاشة إضافة/تعديل المنتج.
- إضافة حقول منفصلة لكل باركود إضافي مع إمكانية حذف أي حقل أو إضافة حقل جديد.
- عند مسح باركود بالكاميرا: يُملأ الباركود الأساسي إذا كان فارغاً، وإلا يُضاف الرمز كأحد الباركودات الإضافية دون تكرار داخل المنتج.
- تبقى جميع الباركودات الإضافية مرتبطة بنفس سجل المنتج ومخزونه وسعره، وتُستخدم للبحث والبيع مثل الباركود الأساسي.

ملاحظة التحقق: تم تعديل ملفات المصدر داخل المشروع. لم يتم تنفيذ بناء Windows هنا لأن حزم المشروع غير مثبتة في بيئة العمل؛ يجب تشغيل GitHub Actions للتحقق من البناء وإنتاج ملف EXE.
