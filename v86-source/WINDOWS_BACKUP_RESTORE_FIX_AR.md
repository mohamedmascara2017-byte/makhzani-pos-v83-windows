# تحديث مخزني Windows

## الإصلاحات
- تثبيت عنوان تشغيل تطبيق Electron على `http://127.0.0.1:32145` بدلاً من اختيار منفذ عشوائي عند كل تشغيل. هذا مهم لأن AsyncStorage على الويب يخزن البيانات بحسب عنوان الموقع؛ تغيير المنفذ كان يجعل التطبيق يبدو وكأنه يبدأ من الصفر.
- تفعيل قفل نسخة واحدة من التطبيق والتركيز على النافذة الموجودة عند محاولة فتح نسخة ثانية.
- توحيد/تطبيع حقول المنتجات الرقمية والباركود عند تحميل البيانات أو استعادة النسخة، لتجنب قيم نصية أو حقول ناقصة تعطل حساب المخزون وإتمام البيع.
- حفظ اختيارات اختصارات البيع ضمن بيانات المتجر والنسخة الاحتياطية.
- إضافة شاشة إدارة اختصارات البيع: اختيار المنتجات وإلغاء اختيارها، بما فيها المنتجات ذات الباركود. الاختيارات تحفظ تلقائياً.
- الإبقاء على صيغة النسخ الاحتياطية `makhzani-pos-backup-v1` والتوافق مع النسخ القديمة؛ إذا لم تتضمن النسخة اختصارات مخصصة، يبقى السلوك القديم لأول 16 منتجاً دون باركود.

## بناء نسخة Windows
من مجلد المشروع:
1. `pnpm install`
2. `pnpm --filter @workspace/makhzani-pos run desktop:dist`

ملف التثبيت الناتج داخل `artifacts/makhzani-pos/release/`.
