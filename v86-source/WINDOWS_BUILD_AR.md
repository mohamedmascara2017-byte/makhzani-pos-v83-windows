# مخزني POS — تجهيز نسخة Windows

هذه الحزمة مبنية على ملف المشروع الذي أرسله المستخدم، وتضيف غلاف Electron وإعداد تصدير Expo للويب ومهمة GitHub Actions لبناء مثبت Windows بصيغة EXE.

## ما الذي تم تغييره؟
- إضافة `build:web` لتصدير تطبيق Expo إلى ملفات ويب ثابتة.
- إضافة Electron لعرض نفس واجهة التطبيق داخل نافذة Windows مستقلة.
- إضافة مثبت NSIS قابل للتثبيت وإمكانية اختيار مجلد التثبيت.
- إضافة سير عمل `.github/workflows/build-windows.yml` يعمل يدوياً أو عند تحديث ملفات التطبيق.
- إبقاء ملفات الشاشات والميزات الحالية كما هي؛ لم يتم حذف التقارير أو المبيعات أو المخزون أو العروض.

## طريقة البناء على GitHub
1. ارفع محتويات هذا المجلد إلى جذر المستودع، مع دمج الملفات الجديدة وعدم حذف سير عمل Android الحالي.
2. افتح GitHub ثم Actions.
3. اختر `Build Makhzani POS Windows EXE`.
4. اضغط `Run workflow` وانتظر انتهاء المهمة.
5. من صفحة التشغيل الناجح افتح Artifacts وحمّل `Makhzani-POS-Windows-Installer`.
6. فك ضغط الملف المحمّل وشغّل ملف EXE على Windows 10/11.

## تنبيهات مهمة قبل الاعتماد في المحل
- هذه حزمة مصدر وإعداد بناء وليست ملف EXE مبنياً أو مختبراً بعد. يجب أن ينجح GitHub Actions أولاً.
- بيانات نسخة الحاسوب ستكون محلية على ذلك الحاسوب. لا توجد مزامنة هاتف/حاسوب في هذه المرحلة.
- واجهة الويب تستخدم تخزين AsyncStorage عبر دعم الويب؛ يجب اختبار حفظ البيانات بعد إغلاق البرنامج وفتحه، وتصدير/استيراد JSON.
- الكاميرا والباركود والاستيراد/التصدير والطباعة تحتاج اختباراً فعلياً على Windows. قد تحتاج بعض واجهات الهاتف إلى تعديلات خاصة بالويب/سطح المكتب إذا ظهرت أخطاء أثناء البناء أو الاختبار.
- لا تعتمد النسخة في البيع الحقيقي قبل اختبار عملية بيع ومرتجع ومصاريف وتقارير ونسخة احتياطية على بيانات تجريبية.


## إصلاح شاشة Windows البيضاء والاختصارات السريعة

- تطبيق Electron يعرض الآن ملفات الويب عبر خادم محلي على 127.0.0.1 بدلاً من فتح index.html عبر file://، لتعمل مسارات ملفات Expo الثابتة بشكل صحيح.
- تبويبات Liquid Glass الأصلية محصورة في iOS؛ نسخة Windows تستخدم تبويبات الويب العادية.
- في شاشة البيع تظهر تلقائياً اختصارات لكل المنتجات التي لا تملك باركود ولديها مخزون متاح. الضغط على المنتج يضيف وحدة واحدة إلى الفاتورة.
